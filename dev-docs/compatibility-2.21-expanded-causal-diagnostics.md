# Dev 2.21 expanded causal diagnostics

Dev 2.21 preserves the verified Dev 2.20 work and adds only bounded,
read-only evidence for the additional titles selected from the Dev 2.19
device review. It does not claim that these observations are compatibility
fixes and does not fabricate media, network, graphics, input, resource or
object success.

## Included tests

| Title | Classification | Change in this build | Prediction and falsifier |
| --- | --- | --- | --- |

## Deliberate exclusions

- JellyCar 3, Splode, SUPERFALL and Tiki Totems 2 already have precise
  machine-code/lifetime sites. Their next progress requires offline caller
  disassembly and watched-address placement, not another unchanged device run.
- Topple 2 passes a `UIColor` where a `CGColorRef` is required; accepting this
  globally would hide invalid guest API use.
- Trenches VS mutates an array during Foundation enumeration; changing global
  enumeration semantics would invent behavior.
- ADVENA and ZENONIA 2 require historical offline/network and exception
  semantics, not broad success stubs.

## Boundedness and validation

The new recorder storage is fixed: 64 focused Objective-C boundaries, 64 KVO
events, 32 media events and 64 GL visual calls. It performs no per-event log
output during gameplay. GL history is dumped only once on return or failure;
dispatch provenance is printed only at an actual strict dispatch failure.

Focused tests cover GL history retention/bounds and the existing Dev 2.20
contracts. Hosted compilation and test results, skipped/allowed-to-fail steps,
package identity and artifact verification are recorded separately. Physical
device behavior remains pending.
